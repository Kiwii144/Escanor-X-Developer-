API အသုံးပြုနည်း အခြေခံ

ESCANOR-X Reseller API သည် SmileOne B2B Gateway ကတဆင့် Game Diamond/Credit များ Topup ပြုလုပ်နိုင်သော RESTful API တစ်ခုဖြစ်သည်။ Request အားလုံး JSON format ဖြင့် ပေးပို့ရမည်ဖြစ်ပြီး Response များလည်း JSON ဖြင့် ပြန်လည်ရရှိမည်ဖြစ်သည်။

ℹ API Key ရရှိလိုပါက Telegram @EscanorX_Official သို့ဆက်သွယ်ပါ သို့မဟုတ် api.escanorx@gmail.com သို့ Email ပေးပို့ပါ။
Supported Regions

🇧🇷 BR — Brazil (SmileOne BR) — Smile Coins သုံးသည်
🇵🇭 PH — Philippines (SmileOne PH) — PHP amount သုံးသည်

🔑
Authentication
API Key ဖြင့် Request တိုင်းကို Authenticate လုပ်ရမည်

Request တိုင်းတွင် X-API-Key HTTP Header ထည့်ရမည်။ API Key မပါပါက 401 Unauthorized ပြန်လာမည်ဖြစ်သည်။

Header Format
X-API-Key: your_api_key_here
Example Request (cURL)
# cURL နမူနာ
curl -X POST https://smileone.escanorx.com/api/v1/products/list \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your_api_key_here" \
  -d '{"product": "mobilelegends", "country": "br"}'
Example Request (Python)
# Python requests နမူနာ
import requests

headers = {
  "X-API-Key": "your_api_key_here",
  "Content-Type": "application/json"
}

response = requests.post(
  "https://smileone.escanorx.com/api/v1/products/list",
  json={"product": "mobilelegends", "country": "br"},
  headers=headers
)
print(response.json())

GET /api/v1/products/balance ကိုယ့် Balance ကြည့်

လက်ရှိ Reseller Account ၏ BR နှင့် PH Balance ကို ကြည့်ရှုနိုင်သည်။ Request Body မလိုပါ။

ℹ BR Balance: SmileCoins (BR region အတွက်) | PH Balance: PHP Amount (Philippines region)
Response Example
{
  "success": true,

Orders
Diamond/Credit Topup Order ဖန်တီးခြင်းနှင့် စီမံခန့်ခွဲမှု
POST /api/v1/orders/create Order ဖန်တီး (Topup)

Game Topup Order တစ်ခုဖန်တီးသည်။ Balance ပြတ်ဆဲလျှင် Error ပြန်လာမည်။ Order အောင်မြင်ပါက Balance ကို Auto-deduct ပြုလုပ်မည်။

Request Body
FieldTypeRequiredDescription
productstringrequiredGame product name (e.g. mobilelegends)
product_idstringrequiredDiamond pack ID (/products/list မှ ယူရမည်)
user_idstringrequiredPlayer ၏ Game User ID
zone_idstringrequiredZone/Server ID (MLBB: zone, FF: server, မလိုသော game: user_id ထပ်ထည့်)
countrystringoptional"br" သို့မဟုတ် "ph" — default: "br"
pricefloatrequired/products/list မှ ရသော price တိတိကျကျ ထည့်ရမည်
discountfloatoptionalDiscount amount — default: 0.0 (system မှ auto-verify ပြုလုပ်မည်)
Cost Calculation

🇧🇷 BR Region: Cost = (price − discount) × 10 SmileCoins
🇵🇭 PH Region: Cost = price (PHP) — B2B price ဖြစ်သောကြောင့် discount မနုတ်

Request Example (MLBB - BR)
{
  "product": "mobilelegends",
  "product_id": "2195",
  "user_id": "123456789",
  "zone_id": "1234",
  "country": "br",
  "price": 0.99
}
Success Response
{

  "message": "Done",

Failed Response

  "success": false,

Redeem
SmileOne Redeem Codes ကို Balance အဖြစ် ပြောင်းလဲမှု
POST /api/v1/redeem/codes Redeem Codes ရိတ်

SmileOne Redeem Code (၁ ခုမှ ၂၀ ခုထိ) တစ်ခါတည်း Redeem ပြုလုပ်နိုင်သည်။ အောင်မြင်ပါက Balance ကို Auto-credit ပြုလုပ်မည်။

⚠ တစ်ကြိမ်လျှင် အများဆုံး 20 codes သာ ထည့်နိုင်သည်။ 20 ကျော်ပါက error ပြန်လာမည်။
Request Body
FieldTypeRequiredDescription
codesarray[string]requiredRedeem Code များ (max 20)
Request Example
{
  "codes": [
    "AFB446904B8",
    "9899FF6FB51",
    "CFDDC226A08"
  ]
}
Response Example
{
  "success": true,
  "client": "YourShopName",
  "summary": {
    "total": 3,
    "success": 2,
    "failed": 1
  },
  "results": [
    {"code": "AFB446904B8", "status": "success", "amount": 100, "country": "brasil"},
    {"code": "9899FF6FB51", "status": "success", "amount": 50, "country": "philippines"},
    {"code": "CFDDC226A08", "status": "failed", "message": "Code used"}
  ]
}
ℹ Smile One Code သည် "brazil" ဖြစ်ပါက BR Balance သို့ ထည့်သွင်းမည်။ "philippines" ဖြစ်ပါက PH Balance သို့ ထည့်သွင်းမည်။
⚡
Error Codes
HTTP Status Code နှင့် အဓိပ္ပာယ်
Statusအဓိပ္ပာယ်ဖြစ်ရသည့်အကြောင်းရင်း
200 OK အောင်မြင်သည် Request အောင်မြင်ပြီး data ပြန်လာသည်
400 Bad Request Price မမှန်ကန်ပါ / Code မပါ / Region မမှန်ပါ
401 Unauthorized X-API-Key header မပါပါ / Token Expired
402 Payment Required Balance မလုံလောက်ပါ — Balance ဖြည့်ရမည်
403 Forbidden API Key မမှန်ကန် / Inactive ဖြစ်နေသည်
404 Not Found Order ID မတွေ့ပါ
500 Server Error SmileOne API ချိတ်ဆက်မှု ပြဿနာ / Internal Error
503 Service Unavailable Database ချိတ်ဆက်မှု ပြဿနာ / Cookie Expired
Error Response Format
{
  "detail": "Error message ဒီမှာ ရှိသည်"
}
